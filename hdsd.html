1. Cấu Hình API Key & Phòng Thủ Quá Tải

Để tự do tra cứu mọi từ vựng mới không giới hạn, hãy cấu hình khóa API cá nhân của bạn:

Hướng dẫn lấy Gemini API Key miễn phí

Các bước thực hiện trên Google AI Studio:

  1. Truy cập Google AI Studio và đăng nhập bằng tài khoản Google.
  2. Nhấp vào nút Get API key ở thanh công cụ bên trái (hoặc nút Create API Key).
  3. Nhấp vào nút Create API Key màu xanh dương.
  4. Chọn Create API Key in new project để tạo khóa mới miễn phí.
  5. Sao chép chuỗi mã khóa được hiển thị (bắt đầu bằng ký tự AIzaSy...).

Cách nhập vào ứng dụng:

Click vào biểu tượng (Bánh răng cài đặt) ở góc trên bên phải ứng dụng Hán Tự, dán khóa vào ô Gemini API Key, chọn Mô hình rồi nhấn Lưu cấu hình.

Cơ chế phòng thủ quá tải đa tầng

Nhờ cơ chế tự động bảo vệ tích hợp sẵn, bạn hoàn toàn không lo ứng dụng bị đứt gãy trải nghiệm:

  • Tự động thử lại (Retry with Backoff): Tự phát hiện cổng bận (503) hoặc chạm hạn mức giây (429) để trì hoãn tự động thử lại sau vài giây.
  • Xoay vòng mô hình (Fallback Chain): Nếu mô hình chính bị nghẽn hoàn toàn, hệ thống tự động xoay chuyển tiếp năng lực qua các mô hình dự phòng kế tiếp.
  • Động cơ cục bộ (Local AI Engine): Nếu không kết nối được Internet hoặc API Key hết lượt gọi trong ngày, ứng dụng tự động bóc tách từ vựng tức thì từ kho dữ liệu offline có sẵn.

2. Hướng Dẫn Khởi Động Nhanh

Để bắt đầu hành trình bóc tách chữ Hán, bạn chỉ cần thực hiện 3 bước đơn giản sau:

  1. No. 01
    Nhập từ cần tra: Gõ từ hoặc chữ Hán bất kỳ (Ví dụ: 應該 hoặc 危險) vào thanh tìm kiếm ở khung bên trái.
  2. No. 02
    Bấm Phân tích: Nhấn phím Enter hoặc click nút mũi tên màu đỏ.
  3. No. 03
    Tận hưởng kết quả: Màn hình sẽ hiển thị cấu trúc chi tiết, câu chuyện liên tưởng và các hướng dẫn học tập sinh động.

Lưu ý: Nếu chưa cấu hình API Key, hệ thống sẽ sử dụng Cơ sở dữ liệu mẫu nhanh đối với các từ demo hoặc chuyển sang Local AI Engine để hiển thị phân tích cơ bản ngoại tuyến.

3. Sức Mạnh Trình Phân Tích AI

Trình phân tích thông minh bóc tách một từ thành 4 phần dữ liệu cốt lõi giúp tối ưu hóa việc ghi nhớ:

Bóc tách bộ thủ

Bẻ khóa ký tự thành các nét ghép bộ thủ độc lập kèm giải thích cặn kẽ ý nghĩa tượng hình cổ của bộ thủ đó.

Câu chuyện liên tưởng

Liên kết ý nghĩa của từng bộ thủ thành một câu chuyện ngắn thú vị, biến lý thuyết khô khan thành ký ức hình ảnh sinh động.

Phát âm chuẩn xác

Công nghệ TTS hỗ trợ nghe phát âm trực tiếp cho cả từ vựng trung tâm lẫn các câu ví dụ ngữ cảnh đính kèm.

Hướng dẫn nét thuận

Cung cấp thứ tự từng nét viết (Stroke Order) để bạn luyện tập đúng chuẩn quy tắc bút thuận Trung Hoa.

4. Điện Ảnh Thư Họa Động (Visual Cinema)

Tính năng độc bản giúp biến quá trình chuyển chữ Hán thành hội họa động qua 3 giai đoạn trực giác:

Giai đoạn 1: Bóc Tách Bộ Thủ (Phân cực)

Các bộ thủ bay lơ lửng bóc rời khỏi chữ gốc để bạn ghi nhớ thành phần cấu tạo.

Giai đoạn 2: Loang Mực Thư Pháp (Hội Tụ)

Chữ Hán chính thức được viết đè lên với hiệu ứng loang mực thư pháp mềm mại, sinh động.

Giai đoạn 3: Hóa Hình Câu Chuyện (Visual Collage)

Hội tụ các khối biểu tượng Emoji gợi nhớ câu chuyện giúp khắc sâu liên tưởng thị giác.

5. Bảng Luyện Viết Cảm Ứng

Cơ chế luyện viết thư pháp kỹ thuật số giúp bạn nhớ sâu nét chữ:

  • Hình nền nét mẫu mờ: Bảng vẽ tích hợp in mờ bóng chữ Hán hiện tại phía dưới làm nét vẽ mẫu chuẩn.
  • Độ dày cọ động: Cọ vẽ mô phỏng nét bút lông trung hoa dựa trên tốc độ di chuột hoặc ngón tay cảm ứng (di chuyển nhanh nét thanh, dừng nhấn nét đậm).
  • Xóa viết lại nhanh: Chỉ với một cú bấm "Xóa", bạn có thể luyện tập lại từ đầu vô số lần.

6. Phương Pháp Ôn Luyện Thẻ Nhớ (SRS)

Khi click chọn tab Luyện Tập (SRS) ở thanh tiêu đề, bạn sẽ bước vào không gian ôn tập tối ưu hóa trí nhớ:

Thẻ lật 2 mặt (Flashcards)

Mặt trước hiển thị mặt chữ Hán lớn để thử thách phản xạ. Chạm vào thẻ để lật mặt sau xem phiên âm, nghĩa và câu chuyện chiết tự gợi nhớ.

Phân phối 3 mức độ nhớ (Spaced Repetition)

Đánh giá trạng thái ghi nhớ của bạn bằng 3 nút: Mới học (New), Đang ôn (Learning), và Đã thuộc (Mastered). Hệ thống lưu trạng thái độc lập vào Sổ tay để ưu tiên hiển thị các từ khó.

Xáo trộn ngẫu nhiên

Bấm nút "Xáo trộn thẻ" để đảo lộn thứ tự từ vựng, tránh hiện tượng bộ não ghi nhớ theo thói quen thứ tự trước sau.
