Cấu hình Gemini API Key

Dán khóa Gemini API Key cá nhân của bạn vào đây hoặc chỉnh sửa trực tiếp hằng số DIRECT_API_KEY ở dòng 350 của file nguồn.

Phòng thủ quá tải đa tầng:

Hệ thống tự động xoay vòng qua 3 mô hình (Gemini 2.5 Flash, 2.0 Flash, 1.5 Flash) kết hợp cơ chế tự động thử lại thông minh khi máy chủ bận. Nếu toàn bộ cổng bị nghẽn, Local AI Engine ngoại tuyến sẽ tự kích hoạt ngay lập tức.
